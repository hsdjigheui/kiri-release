## 功能简介

### 支持的应用

| 应用 | 支持版本 |
|---|---|
| 快手 | 14.10.x |
| 抖音 | 40.9.x |
| 小红书 | 9.52.x |
| 红果短剧 | 7.4.3.x |

### 核心能力

**界面精简**
隐藏顶栏、底栏、侧边按钮、评论区、推荐条等任意控件。提供元素扫描功能，可自行定位想隐藏的控件，选中后描红框高亮，所见即所得。

**沉浸显示**
视频画面延伸至状态栏与导航栏区域，底栏背景透明，切换页面不闪烁。支持主页与播放页分别开关。

**透明度调节**
顶部、左侧、右侧、底部、进度条等区域分别调节透明度，播放中与暂停时可设不同值。

**去广告**
拦截开屏广告、弹窗广告、横幅广告、激励视频、短剧插屏等。

**视频下载**
保存视频、图文、音频，可选择是否去水印，保存目录可自定义。

**评论管理**
评论屏蔽词过滤、隐藏点赞、显示完整时间、查看评论时自动暂停视频。

**消息与社交**（抖音）
保留撤回消息、保留阅后即焚、语音转发、已读不回传、隐藏输入状态、火花天数显示等。

**手势交互**
双击动作自定义、长按倍速播放、首页 tab 静音、取消点赞收藏二次确认。

**配置管理**
配置导出与导入、跨设备迁移、一键清除、定时退出。

## 安装

### 环境要求

- Android 8.0（API 26）及以上
- 已安装 LSPosed（API 100+）
- 设备已 Root，或运行在支持 LSPosed 的环境中

### 步骤

1. 下载并安装 `app-release.apk`
2. 打开 **LSPosed 管理器**，进入「模块」页
3. 启用 **Kiri Toolkit**
4. 在该模块的「作用域」中勾选需要生效的应用（快手 / 抖音 / 小红书 / 红果）
5. 强制停止目标应用，然后重新打开

> 安装后若桌面没有图标，属正常现象。模块入口在 LSPosed 管理器的「模块设置」中。

---

## 使用

打开模块配置有两个入口：

- **LSPosed 管理器** → 模块 → Kiri Toolkit → 模块设置
- **宿主应用内** → 分享面板底栏 / 设置页右上角的「模块设置」入口

两个入口进入同一个配置面板，改动即时同步，无需重启。

### 主页操作

| 操作 | 效果 |
|---|---|
| 点击版本号 | 查看更新日志 |
| 长按版本号 | 检查更新 / 修改更新源 |
| 右上角备份图标 | 备份、恢复、清除配置 |

---

## 应用内更新

模块内置更新检查，主页长按版本号即可触发。

更新源默认为本仓库的 `update.json`。若访问不畅，可在「修改更新源」中换成镜像地址：

```
https://ghfast.top/https://raw.githubusercontent.com/hsdjigheui/kiri-release/main/update.json
```

下载完成后会校验 SHA-256，与 `update.json` 记录不一致则拒绝安装。

## 常见问题

**改了设置没生效**

强制停止目标应用后重新打开。模块在宿主进程启动时挂载。

**覆盖安装新版本后功能没变化**

宿主可能仍在运行旧版本模块。请强制停止目标应用，或重启设备。

**面板里找不到某个开关**

该功能可能尚未适配当前的宿主版本。在更新日志弹窗进入「诊断」，查看该功能的挂载状态与失败原因。

**下载更新失败**

`raw.githubusercontent.com` 在国内访问不稳定，请在「修改更新源」中替换为镜像地址。
